Last review of the references below: **2026-09-22**.

This is a curated baseline for the technologies covered by the assessment. Microsoft documentation and product capabilities evolve continuously, so the links should be reviewed whenever the assessment version is updated.

## Content rule

Examples in the product must remain **organization-neutral**. Use generic examples such as customer data, workforce data, financial information, contracts, intellectual property, credentials and supplier data.

Do not place real customer names, sector-specific terminology from a customer engagement, or customer-specific operating assumptions in the built-in assessment.

When a customer-specific workshop is needed, capture the organization and session in the run context or create a separate custom assessment package.
