# Roadmap

## Implemented in the initial foundation

- React/TypeScript PWA shell
- Italian and English UI
- light/dark themes
- assessment catalog
- slide-like introductory narrative
- Essential / Full assessment modes
- IndexedDB autosave
- Microsoft Security & Data Governance assessment
- maturity scoring and area chart
- priority gap list
- JSON / CSV / HTML result export
- browser print / save-to-PDF
- assessment package import/export
- deep validation for assessment definitions and imported packages
- complete local workspace backup / restore with schema migration
- evidence attachments stored locally in IndexedDB
- evidence files included in result JSON and workspace backups
- visual assessment builder for custom assessments
- edit / delete lifecycle for imported assessments
- result history and maturity trend comparison
- per-area delta comparison between comparable runs
- GitHub Pages deployment workflow
- CI workflow

## Next iterations

- configurable scoring models
- richer result action plans and recommendation templates
- organization branding / white-label themes
- optional encrypted backup file
- optional cloud sync adapter
- automated accessibility checks and E2E tests
- dependency maintenance / security audit automation
